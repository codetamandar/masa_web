بازی نانا — نسخهٔ نهایی با موی مشکی و عینک

اجرا: ابتدا ZIP را کامل استخراج کن، سپس index.html را با مرورگر باز کن.
پوشهٔ assets باید کنار index.html باقی بماند.

index.html: ساختار صفحه
style.css: ظاهر و طراحی واکنش‌گرا
game.js: منطق سه مرحله، کنترل‌ها و صداها
assets/: تصاویر بازی

نیازی به نصب پکیج نیست. صدا با اولین کلیک یا لمس فعال می‌شود.
برای ویرایش می‌توانی پوشه را در VS Code باز کنی.
